Urban Threads is an e-commerce data analysis project focused on Q4 orders and returns.  
The data was cleaned and analyzed to identify sales, customer, product, and return patterns.  
I created an interactive Excel dashboard to visualize key KPIs and business insights from the data.  
The dashboard covers orders, revenue, return rate, customer segments, products, and sales channels.  
The analysis provides data-driven recommendations to reduce returns and improve business performance.
